# Llanquihue Tour App

**Descripción:**  
Sistema básico en Java orientado a objetos para gestionar el catálogo de tours de la agencia Llanquihue Tour mediante la lectura de archivos de texto planos y el manejo de colecciones dinámicas (`ArrayList`).

**Estructura de carpetas:**
- `src/model/`: Contiene la clase `Tour.java` que modela la entidad principal.
- `src/data/`: Contiene la clase `GestorDatos.java` encargada de leer el archivo `.txt` y poblar la lista.
- `src/ui/`: Contiene la clase principal `Main.java` que ejecuta el recorrido y filtrado de datos.
- `src/resources/`: Contiene el archivo de datos `tours.txt`.

**Instrucciones para ejecutar la clase Main:**
1. Clonar o descargar el repositorio en el equipo local.
2. Abrir la carpeta del proyecto en IntelliJ IDEA.
3. Verificar que el archivo `tours.txt` esté ubicado dentro de `src/resources/`.
4. Dirigirse a `src/ui/Main.java` y ejecutar el método `main()`.
